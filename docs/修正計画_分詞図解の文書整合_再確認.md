## 4. 修正内容

### 4-1. Phase 2の現在仕様を明確にする

対象: `docs/実装計画_分詞概論と各論の図解教材化.md` の「Phase 2 — 第2試作: 補語としての分詞」

修正前:

```text
320pxでS / O → Cの対応を上下方向へ変換する。
```

修正後:

```text
320pxではS = C／O = Cの2スロットを1列にし、縦へ並べる。
```

意図:

- 矢印を使う旧仕様を、現在の`=`表記へ合わせる。
- `=`には方向がないため、「上下方向へ変換」ではなくレイアウト上の「縦へ並べる」と記述する。
- `S + V + C`／`S + V + O + C`という語順anchorと、`S = C`／`O = C`という叙述関係を混同しない。

### 4-2. 元の実装計画の修正後実測値を訂正する

対象: 同文書「15-2. 実ブラウザ実測」の知覚動詞行

修正前:

```text
知覚動詞 | 350.9 | 393.7 | 470.0 | 520.3
```

修正後:

```text
知覚動詞 | 350.9 | 393.7 | 470.0 | 493.3
```

表の列順は`1280px / 640px / 375px / 320px`のまま維持する。

### 4-3. 修正計画の実装結果を訂正する

対象: `docs/修正計画_分詞図解の教材精度と計画整合.md` の「9-2. 実測と検証」

修正前:

```text
知覚動詞図解の高さ: 320px 520.3px、375px 470.0px、640px 393.7px、1280px 350.9px
```

修正後:

```text
知覚動詞図解の高さ: 320px 493.3px、375px 470.0px、640px 393.7px、1280px 350.9px
```

### 4-4. 修正前の履歴値を保持する

同じ修正計画の「修正前の実測値」にある`520.3px`は変更しない。

この値は旧anchor `see / hear + O + -ing / p.p. / 原形`を表示していた時点の基準値であり、誤記ではない。修正前と修正後を区別できるよう、次のように扱う。

| 記録の意味 | 320px高 | 対応 |
| --- | ---: | --- |
| 修正前の基準値 | `520.3px` | 保持する |
| 修正後の実装結果 | `493.3px` | 現在値へ訂正する |

### 4-5. 歴史記録の旧表記を保持する

元の実装計画「15-4. 段階別の内部検証記録」にある、当時の`S → C`／`O → C`を説明する記述は変更しない。

これは現在仕様を指示する文ではなく、変更前に何を確認したかを残す履歴である。旧表記を機械的に全置換しない。
